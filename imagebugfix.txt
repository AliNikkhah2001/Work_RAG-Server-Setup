1. FINDINGS (why dana-rag-prod Build images failed)
-------------------------------------------------------------------------------

Builds #21 / #22 failed at "Build images" with:

    docker: command not found

Root cause:
  - docker-compose.h200.yml historically bind-mounted the HOST /usr/bin/docker
    into the Jenkins container.
  - Host Docker CLIs are dynamically linked. Inside the container the ELF
    interpreter (ld-linux) is missing → kernel ENOENT → bash prints
    "command not found" (looks like PATH, but it is not).
  - The pinned plugin-rich image dana-jenkins:production also lacked a working
    static /usr/local/bin/docker.
  - Iran mirrors / dash `source` issues were separate and already fixed earlier;
    after those fixed, the real blocker was the missing/broken docker CLI.

Do NOT re-add the host /usr/bin/docker bind-mount.
Do NOT switch the controller to bare jenkins/jenkins:lts (drops Multibranch jobs).
Do NOT run `pkill python` on this host.
