High-Level Architecture Detail

Abstraction-boundary views separating the H200 host (bare metal / venv) from the Docker data plane, and the high-level MVP request flow.

2.1 Service Topology — High-Level Black Box View

Diagram: H200 host vs Docker data plane (black box)

flowchart TB subgraph HOST["H200 host — bare metal / venv (black box)"] MG[Manager :9000 — OpenAI gateway] INF[LLM backends — Gemma / TRT-LLM / DeepSeek / Qwen] EMB[Embedding services :8001-8003] end subgraph DOCKER_PLANE["Docker containers — docker-compose.yml (black box)"] DP[Data plane — Redis / Qdrant / pgvector / Milvus / Open WebUI] end MG -.-> INF MG --> EMB DP -.-> MG EMB -.-> DP
Caption: Service topology — high-level black box view (H200 host vs Docker data plane).
  • The H200 host runs bare-metal / venv processes: the Manager :9000 OpenAI gateway, LLM backends (Gemma / TRT-LLM / DeepSeek / Qwen), and embedding services on :8001–8003.
  • The Docker data plane runs via docker-compose.yml: Redis, Qdrant, pgvector, Milvus, and Open WebUI.
  • The Manager talks to LLM backends and embedding services; the data plane talks back to the Manager; embedding services write to the data plane.
  • This is an abstraction boundary — internal ports and container details are hidden behind each subgraph.

2.2 MVP Integration Point — High-Level Black Box View

Diagram: MVP request flow (host vs Docker boundary)

flowchart LR subgraph HOST["H200 host (black box)"] API[Orchestrator :8100] MG[Manager :9000] LLM[Gemma champion :8010] end subgraph DOCKER["Docker containers (black box)"] UI[Open WebUI :13000] DS[Data plane — Redis / Qdrant / pgvector / Milvus] end UI --> API API --> MG MG --> LLM
Caption: MVP integration point — high-level black box view (host vs Docker boundary).
  • Open WebUI :13000 sends the chat request to the Orchestrator :8100.
  • The Orchestrator calls the Manager :9000 OpenAI gateway.
  • The Manager routes to the Gemma champion LLM on :8010 via Triton promotion.
  • Open WebUI and the data plane (Redis / Qdrant / pgvector / Milvus) live in Docker containers.
  • This view hides internal sub-component details behind host/Docker boundaries.
