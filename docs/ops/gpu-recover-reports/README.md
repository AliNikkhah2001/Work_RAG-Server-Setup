## Incident note — 2026-11-16 — Jenkins Build images (`docker` CLI)

Hourly reports stayed **HEALTHY** (prod stack / QA) while `dana-rag-prod` builds
failed at **Build images**. Evidence under `meta/jenkins/`:

| Phase | Console / ci-evidence | Meaning |
|---|---|---|
| Earlier | `docker: command not found` | No working CLI in controller (broken/missing `/usr/local/bin/docker`; host bind-mount ELF ENOENT) |
| Later | `unknown shorthand flag: 'f' in -f` | Static `docker` in `.ci-bin/` but **no compose plugin** — `docker compose -f` parsed as docker flags |
| Mislabel | diagnosis tip about npm / WebUI skip | Secondary; real gate was compose build failing instantly |

**Cause:** code on umbrella `main` (#95–#100) was present, but the running
controller was recreated **without** `docker-compose.h200.yml` and the image was
never rebaked with a static CLI + compose plugin. Merges on a laptop do not apply
themselves to `dana-jenkins-prod`.

**Apply on GPU:** see repo-root `imagebugfix.txt` (Server-Setup PR #6) and umbrella
`bash scripts/bootstrap_jenkins_docker_cli.sh --commit` **or**
`docker build -f deploy/jenkins/Dockerfile.docker-cli …`, then:

```bash
docker compose -f deploy/jenkins/docker-compose.yml \
  -f deploy/jenkins/docker-compose.gpu.yml \
  -f deploy/jenkins/docker-compose.h200.yml up -d
```

**Do not** recreate with only yml+gpu (heal/restore scripts previously did this —
fixed to always include h200 when present). **Do not** remount host `/usr/bin/docker`.

**Submodules:** child-repo merges need an umbrella gitlink bump + `[ci prod]` before
Jenkins builds them; until Build images works, no submodule tip can land in images.
