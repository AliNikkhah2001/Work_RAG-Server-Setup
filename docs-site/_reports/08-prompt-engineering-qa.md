### 4e. Prompt engineering — vanilla vs improved, full Q&A

For each task, the *same tricky question* is asked twice on a strong model (Gemma-4-31B) and an error-prone model (Mistral-7B): first with the raw dataset prompt (**vanilla**), then with an improved Persian prompt built from the 4-component framework — **ROLE** (شما …), **CONTEXT** (what the task is), **CONSTRAINTS** (what not to write: no prose, no explanation, single answer), **OUTPUT FORMAT** (the exact shape the scorer expects). Answers are shown in full (untruncated). `✓/✗` = model hit the gold answer.
